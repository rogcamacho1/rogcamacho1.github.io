Política de privacidade

Hermes Rodrigo é um assistente pessoal de uso privado de Rodrigo Camacho. Somente a conta Google do próprio Rodrigo usa este aplicativo.

Que dados acessa

Com autorização do titular da conta, o aplicativo lê e organiza dados da conta Google dele: agenda, e-mails, arquivos do Drive, planilhas, documentos e contatos.

Como usa

Os dados são usados apenas para servir o próprio titular: montar resumos, organizar compromissos e preparar documentos para ele. Não são vendidos, compartilhados com terceiros nem usados para publicidade.

Onde ficam

O acesso é processado num servidor privado do titular. As credenciais de acesso ficam protegidas nesse servidor e podem ser revogadas a qualquer momento em myaccount.google.com/permissions.

Uso dos dados do Google

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
